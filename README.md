AgriYield proposes a standardized digital approach in which crop-yield information is captured through structured forms and processed into useful indicators. The system separates field data collection from management and analysis while allowing both sides to work from the same information model.
AgriYield is a proposed digital agriculture platform designed to support the collection, management, monitoring and analysis of crop-yield information. The system combines a mobile application for farmers and field officers with a web application for agricultural managers, researchers and administrators. The platform is intended to make crop production information more structured, accessible and useful for decision-making.

Yield per hectare = Harvested Quantity (kg) ÷ Farm Area (hectares)
Example: if a farmer harvests 2,500 kg from a 2-hectare farm, the system calculates 1,250 kg/ha. The full implementation should validate that farm area is greater than zero before performing the calculation.
Processing Workflow
•	User logs into the application where authentication is enabled.
•	User selects or creates a farmer record.
•	User creates or selects the relevant farm.
•	User enters crop and planting information.
•	During or after harvest, the user records harvest date and quantity.
•	The system validates the values.
•	The system calculates yield per hectare.
•	The record is saved or synchronized.
•	Authorized users can view the result on dashboards and reports.
